# Паспорт проекта: Ипотечный консультант

Обновлён: 17 октября 2026
Автор: Татьяна (Zvezda-ts). Собрано вместе с Claude.

## 1. Что это

Дашборд для ипотеки в одном HTML-файле. Считает переплату, сравнивает «сократить срок» и «сократить платёж», разовые досрочки, страховку, рефинансирование и налоговый вычет. Умеет читать ипотечный договор и график платежей (PDF, Word, фото до 30 страниц) через ИИ, выводит сроки с обратным отсчётом, особые условия (рост ставки, аренда, транши ИЖС), пишет персональную консультацию и собирает PDF-отчёт.

Для кого: для себя и как кейс для агентов по недвижимости, кредитных менеджеров, ипотечных брокеров.

## 3. Как восстановить, если что-то пропало

**Пропал Claude-аккаунт или артефакт.**
1. Откройте новый чат в Claude (или другом ИИ-ассистенте с публикацией страниц).
2. Прикрепите `ipoteka_working.html` и напишите: «Опубликуй этот файл как артефакт. Нужны возможности: sample с картинками (images: true) и downloads. Это мой ипотечный консультант, паспорт проекта приложен».
3. Приложите этот паспорт, чтобы ИИ знал контекст.

**Пропал GitHub.**
1. Новый аккаунт, новый публичный репозиторий `ipoteka-demo`.
2. Загрузите туда `ipoteka_demo_index.html` под именем `index.html` и пустой файл `.nojekyll`.
3. Settings → Pages → Deploy from a branch → main / (root) → Save. Через 1-2 минуты сайт живой.

**Демо можно открыть без интернета-хостинга:** просто дважды кликнуть `ipoteka_demo_index.html` на компьютере. Работает всё, кроме ИИ.

**Пропало всё сразу:** ниже раздел 9, мастер-промпт для сборки с нуля.

## 4. Устройство интерфейса

Тёмная тема, лавандовая гамма (по референсу дашборда отдела продаж). Шрифт Onest.
Цвета: фон #1a1d2e, меню #20233a, панели #272a40/#2f3350, лаванда #7a5cc4 / #9b7fd8 / #ab93e0 / #cdbdf0, мята #2fc6a8 (выгода, «сокращаю срок»), коралл #f07c84 (без доплат, срочно), персик #f5b97a (внимание), жёлтый #f3e46b (выбранное, цифры ввода), розовый #e46fbf (аренда).

Слева меню-вкладки с бейджами (по референсу Finance Dashboard), на телефоне меню внизу.

Группа «Расчёт»:
- **Обзор**: 4 плитки (платёж, переплата, экономия, на сколько раньше), строка «Мои данные» с кнопкой «Изменить данные», график остатка долга, блок доплаты с ползунком, три сценария.
- **Досрочки**: разовые досрочки (сумма + через сколько месяцев), второй ползунок доплаты с итогом (внесёте сверху, сэкономите, сколько экономит рубль, последний платёж), таблица доплат 1-20 тысяч.
- **Рефинансирование**: новая ставка + расходы → новый платёж, разница, чистая выгода, окупаемость, цветной вердикт.
- **Вычет**: стоимость жилья, зарплата, уплаченные проценты, галочки «уже получали» и «до 2014». Кнопка «Вложить возврат в досрочку» добавляет разовые досрочки по годам.

Группа «Разбор»:
- **Документы**: загрузка, плитки условий, «Подставить в калькулятор».
- **Сроки и условия**: сроки с обратным отсчётом (коралл до 3 мес, персик до года), особые условия плитками, «на что обратить внимание».
- **Советы**: консультация ИИ, рекомендации, PDF-отчёт.

Бейджи: Вычет (сумма возврата), Советы (число), Документы (галочка), Сроки (месяцы до ближайшего срока), Рефинанс. («выгодно»/«нет»), Досрочки (число).
Ссылка на вкладку: в конце адреса `#overview`, `#early`, `#refi`, `#tax`, `#docs`, `#terms`, `#tips`.
Внизу меню «Очистить всё» с подтверждением на странице.

## 5. Как считается

- Аннуитет: P = S·r / (1 − (1+r)^−n), r = ставка/1200.
- Помесячная симуляция трёх сценариев: без доплат; доплата + сокращение срока (платёж постоянный); доплата + сокращение платежа (платёж пересчитывается каждый месяц на остаток и оставшийся срок).
- Разовые досрочки вычитаются из долга после платежа в указанный месяц.
- Страховка: раз в год, пропорционально остатку долга (страховка в год × остаток / начальный долг).
- Экономия = (проценты + страховка) без доплат минус то же с доплатами.
- Рефинансирование: сравнение платежей и процентов при той же сумме и сроке, окупаемость = расходы / разница платежа.
- Вычет (проверено на 17.10.2026): 2 млн за покупку, 3 млн процентов (без лимита для кредитов до 2014), возврат 13%, при доходе выше 2,4 млн в год 15% (упрощение). В год не больше уплаченного НДФЛ. Источник: Циан, статья о вычете по ипотеке.
- Остаток по договору без графика: аннуитетная формула по числу месяцев с даты договора. Если загружен график, берётся его остаток.
- Рост ставки при потере условия: пересчёт с ставкой + N п.п., разница переплаты и в год.

Проверка на примере: 4,5 млн, 10,5%, 240 мес → платёж 44 927 ₽, переплата 6 282 503 ₽. Доплата 3 000 + сокращение срока: 198 мес.

## 6. Возможности ИИ (только в Claude)

Артефакт объявляет: `sample` с `images: true` и `downloads`.
- Чтение файлов в браузере: pdf.js 3.11.174 (cdnjs, worker подключается скриптом), mammoth 1.6.0 для .docx. Скан PDF рендерится в картинки страниц.
- Фото отправляются пачками по лимиту за запрос, каждая следующая пачка дополняет уже найденное. Максимум 30 фото.
- PDF-отчёт: html2canvas 1.4.1 + jsPDF 2.5.1, светлый отчёт, режется по разделам.
- Вне Claude (GitHub Pages) ИИ недоступен: демо показывает готовый пример разбора и консультации, PDF скачивается обычной ссылкой.

## 7. Промпты ИИ внутри дашборда

### 7.1 Извлечение условий (sample.json)

```
Ты разбираешь документы по ипотеке из России: кредитный договор и, возможно, график платежей. Сегодня {ГГГГ-ММ-ДД}.
Не выписывай персональные данные: ФИО, паспорт, адреса, номера счетов, СНИЛС. Только условия.
Ответь только JSON такого вида (если чего-то нет в документах, ставь null):
{"loan_kind","credit_limit","bank","contract_date","loan_amount","property_price","rate","term_months","payment_type","monthly_payment","program","insurance","insurance_cost_year","rate_if_no_insurance","rate_increase_pp","rate_increase_condition","tranches","deadlines":[{"date","what","penalty"}],"property_notes","early_repayment","rent_restrictions","rate_change","penalties","schedule_balance","schedule_balance_date","schedule_months_left","red_flags":[{"title","detail"}]}
В deadlines положи все сроки обязательств заёмщика (если срок задан как «N месяцев от даты», посчитай дату). Документов может быть несколько: кредитный договор, поручительство, договор купли-продажи, график. Сведи условия из всех. В red_flags 2-5 пунктов (ограничения досрочки и аренды, рост ставки, обязательные страховки, комиссии, условия льготы). Пиши по-русски, просто, без длинных тире.
```
Полный текст с описанием каждого поля в коде, функция `extractPrompt()`.

### 7.2 Консультация (sample, поток)

На вход: JSON условий + все цифры калькулятора (остаток, ставка, срок, платёж, доля дохода, страховка, сценарии, таблица доплат, рефинансирование, вычет).
Разделы: Главное про вашу ипотеку; Что выгоднее именно вам; На что смотреть в договоре (начать со сроков); Сдача в аренду (только если есть ограничения); Рефинансирование и вычет; План на ближайший месяц (3-4 шага). До 500 слов.
Стиль: как пишет знакомый, который разбирается; без длинного тире, без «не X, а Y», без канцелярита и «важно отметить», «ключевой», «является», без эмодзи и морали в конце.
Полный текст в коде, функция `consult()`.

## 8. История: промпты Татьяны по шагам

Чтобы повторить проект в любом ИИ, можно пройти те же шаги.

1. «Я хочу создать дашборд для себя: калькулятор и консультант по ипотеке. Когда я ввожу сумму, ставку, срок и свой доход, хочу видеть переплату и сравнивать варианты: что если платить на 3 000 больше или делать досрочные платежи, что выгоднее, сокращать срок или платёж. Сначала задай мне вопросы, потом составь план и сделай первую версию. Сделай понятный интерфейс с крупными цифрами.»
   Ответы на уточнения: действующая ипотека; доплата каждый месяц +N ₽; готовые выводы вместо чата; ссылка в Claude.
2. «Сделай его в премиальных цветах, чтобы он был привлекателен для потенциальных заказчиков.»
3. Референс с цветовой гаммой (тёмный отчёт отдела продаж, лаванда, мята, коралл, жёлтый для выбранного).
4. «Хочу возможность подгрузить ипотечный договор, чтобы рассчитать точечно и индивидуально и получить точечную консультацию. Затем предложи, как ещё улучшить дашборд.»
5. «Улучшаем по твоему предложению, кроме сравнения со вкладом (оставим для брокеров). Чат с ИИ не добавляем, ограничения на сдачу в аренду выделять отдельной рекомендацией.» Добавлены: график платежей, разовые досрочки, рефинансирование, вычет, PDF, страховка.
6. Тест на реальном договоре (кредитная линия ИЖС, 11 фото). Доработки: пачки до 30 фото, понимание кредитных линий, сроки с обратным отсчётом, цена потери льготного условия.
7. «Как очистить дашборд, чтобы подгрузить другие данные?» Кнопка «Очистить всё».
8. Референс Finance Dashboard с вкладками в боковой панели: «Перенести текстовую информацию во вкладки, дашборд слишком длинный. Цвет оставляем лавандовый.»
9. «В разделе Досрочки добавить плашку, чтобы не было пустого места, может продублировать ползунок.»
10. Демо-версия с выдуманным договором, публикация на GitHub Pages.

## 11. Видео и анимация

Записаны скриптом `record_video.py` (Playwright + ffmpeg) по демо-версии, без звука:
- `Ипотечный консультант 16x9.mp4` 1920×1080, 40 сек, для сайта и YouTube
- `Ипотечный консультант 9x16.mp4` 1080×1920, 42 сек, для сторис, Reels, Telegram
- `Ипотечный консультант анимация.gif` 960 px, 7 сек, петля к посту
- `Ипотечный консультант петля для сайта.mp4` 1280 px, 7 сек, лёгкая петля на первый экран сайта

Сценарий: заставка «Ипотечный консультант на ИИ» → Обзор, ползунок доплаты → Документы → Сроки и условия → Рефинансирование (ставка 7,9) → Вычет → Советы → финал «Соберу такую версию под ваше агентство» с адресом демо. Подписи внизу (16:9) или сверху (9:16), жёлтый курсор.

Пересобрать: `python3 record_video.py h` и `python3 record_video.py v`, затем ffmpeg:
`ffmpeg -ss 0.2 -i raw_h.webm -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -r 30 -movflags +faststart -an out.mp4`

## 12. Пост для брокеров (черновик от 17.10.2026)

Структура: боль брокера (клиент спрашивает про досрочку, приходится считать вручную, клиент уходит к тому, кто ответил быстрее) → что делает инструмент → выгода агентству (заявки с сайта, быстрый ответ, доверие, повод написать старым клиентам) → доказательство на реальном договоре ИЖС → предложение под агентство → ссылка на демо и призыв написать.
